# MultiVision Plan6: configurable planar tag inspection

Source: the Driver-approved planar tag query described in this conversation, constrained by ADR-0001's persistent camera ownership, native coordinate model, fail-closed spatial operations and thin API/CLI boundaries, plus the implemented calibration and session authorities. Plan6 adds one-camera, latest-frame inspection of every valid tag detection using a selectable OpenCV dictionary, with optional projector-space planar geometry. Camera-space orientation is explicitly an apparent image-plane angle; projector-space orientation is the rectified planar angle in projector coordinates. Plan6 does not add card semantics, stack interpretation, tracking or 3D pose.

The complete implementation contract and deterministic validation matrix are in the [shared validation contract](plan6-validation-contract.md). Preserve ADR-0001, ADR-0002, ADR-0003 and `harness.toml`.
